# Mockup-Dashboard-Transaction-Google-Looker-Studio-
Created retail transaction dashboard using synthetic dataset using Google Looker Studio. This dashboard was created to exercise designing dashboard, identify Key Performance Index from the data, and developed a simple but useable dashboard. The development of this dashboard also was done with the intention to practice and act as the first step to learn about BI and experience in creating relevant dashboard. /n
